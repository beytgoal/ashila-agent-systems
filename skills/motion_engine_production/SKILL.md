# Motion Engine Video Production

## Build scenes to the production rules

- Start each production from the motion engine assembly script at ~/workspace/goals/serial-animasi-psikologis-10-topik/hidden_files/assemble_universe25.py, and extend it rather than starting a new pipeline.

- Keep motion graphics dominant through the whole video and use stock footage only as short inserts inside the human psychology analogy scenes.

- Sync each footage insert to the narration words it illustrates, for example office stress footage on the line about work getting more toxic and distant couple footage on the line about a relationship getting worse.

- Generate illustrations without frames.

- Honor every text marker, including @@NL@@, in headlines as well as body text, and never let a literal marker string reach the render.

## Mix voice-over to the loudness targets

- Mix the voice-over to -15 LUFS integrated and keep bed music around -34 LUFS (locked config, owner 2026-10-31; previously -16/-38).

- Keep transition SFX (whoosh/impact) quiet at 0.3 relative volume (user correction 2026-10-19, applies from video #6; already in the engine's mix code).

- Tighten the voice-over pacing so narration never leaves long pauses.

## Run the pre-send QA gate on the final file

- Measure integrated loudness of the final rendered file with an ffmpeg loudnorm analysis and send it to the user only when the voice-over reads -15 LUFS within 1 LU (locked config 2026-10-31).

- Extract several frames spread across the render and check that no literal marker text appears, that illustrations have no frames, and that no text collides with the layout.

- When a re-render claims a fix, compare the new file against the previous one. If the audio is unchanged, the fix did not apply, so re-render properly instead of resending.

- Never send a render that skipped this gate.
