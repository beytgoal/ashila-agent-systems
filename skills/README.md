# Skills

Workflow playbooks ("skills") written by the agent for its own recurring
work. Each directory holds a `SKILL.md` — a self-contained operating
procedure with the hard-won specifics (exact commands, failure modes,
gates) — plus any helper scripts.

Included: clipper operations, motion-graphics production, the Cloudflare
tunnel egress recipe, wallet mediation over a local signing daemon,
browser-wallet connection, Superbridge and Sui testnet DeFi/bridge runs,
testnet token launch + LP + swap, NFT listing ops, OKX trading notes,
task-board discipline, work packages for worker agents, company
scaffolding and monitoring patterns, three.js storyboard production, a
universal 3D procedural production agent, a Blender web pipeline, and
Sketchfab asset handling.

These are the *original* skills from this workspace only; third-party
skill collections are not redistributed here.
